# 📚 Feedback de Professores

Um site simples desenvolvido em HTML, CSS e JavaScript que permite aos alunos enviar **elogios** ou **reclamações** sobre professores.

> **Aviso:** Este projeto é apenas para fins educacionais. Caso seja utilizado em uma instituição de ensino, recomenda-se implementar moderação, autenticação de usuários e políticas de uso para evitar abusos.

---

## ✨ Funcionalidades

- Enviar elogios.
- Enviar reclamações.
- Informar o nome do professor.
- Visualizar os feedbacks enviados.
- Interface simples e responsiva.
- Não necessita de banco de dados.

---

## 🚀 Como Executar

1. Baixe ou clone este repositório:

```bash
git clone https://github.com/seu-usuario/feedback-professores.git
```

2. Entre na pasta do projeto.

3. Abra o arquivo `index.html` em qualquer navegador.

Não é necessário instalar dependências ou executar um servidor.

---

## 💻 Como Utilizar

1. Digite o nome do professor.
2. Escolha entre:
   - Elogio
   - Reclamação
3. Escreva sua mensagem.
4. Clique em **Enviar**.
5. O feedback aparecerá na lista abaixo do formulário.

## ⚠️ Considerações

Atualmente, os feedbacks são armazenados apenas na memória da página.

Ao atualizar o navegador, todas as mensagens serão perdidas.

Para uso real, recomenda-se utilizar um banco de dados como:

- MySQL
- PostgreSQL
- Firebase
- MongoDB
